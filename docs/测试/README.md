维护责任：QA；状态：现行；最后核查：2026-11-03。适用范围：VSIX 1.0.1 的回归与后续 Codex 集成验收。当前实现基线为 `d7e6b0d`，本轮接管的文档基线为 `689de24`，工作区仅重建项目文档；本地探针另按文件哈希定位，不视为该提交包含的功能。

本目录负责测试方法、验收场景到证据的映射、回归记录与剩余风险。[验证记录](验证记录.md)保存被检版本、实际结果与本地证据索引；本文维护如何验证。已有测试、历史通过和其他角色的报告均不能替代本轮对应场景的实际执行。

业务预期以[产品规则](../产品/README.md)为准，用户任务见[使用指南](../用户文档/使用指南.md)；实现与数据边界分别见[本地审阅引擎](../客户端/本地审阅引擎.md)、[数据协议](../客户端/数据协议.md)和[客户端](../客户端/README.md)。Codex 的宿主条件见[接入设计](../客户端/Codex接入.md)。测试入口以已跟踪的测试文件和 [CI 工作流](../../.github/workflows/ci.yml)定位，不复制产品条件或字段 schema。

## 验证约定与入口

开发环境与依赖安装见[贡献指南](../../CONTRIBUTING.md#本地开发)。代码或打包变化交付前运行 `npm test` 与 `npm run package`；开发时可先编译，再定向运行相关测试：

```sh
npm run compile
node --test test/comments.test.cjs test/reviews.test.cjs
```

测试只使用临时合成仓库与虚构样例，不隐式启动编辑器、修改安装或操作真实审阅数据。根据变更选择正常路径、错误恢复、归属隔离和回归场景；纯文档变化核对事实、入口与链接，不为数量重复全量测试。

| 证据类型 | 可以支持的结论 | 不能据此推定 |
| --- | --- | --- |
| 静态核查 | 某版本代码、配置、文档或产物的内容 | 运行成功、界面可用或已发布 |
| 单元与模拟测试 | 受控输入下的规则、UI 脚本和模拟桥接结果 | 实际 DOM 布局、真实宿主权限与生命周期 |
| 集成测试 | 真实 Git、文件系统或 stdio 进程在已测场景中的结果 | UI 已展示保存结果、其他宿主同样支持 |
| 真实宿主与界面观察 | 指定宿主、版本和操作下的可见状态及最终落盘结果 | 未测流程、其他平台或完整产品验收 |

每次验证记录日期、提交及未提交差异、产物版本、环境、命令或操作、预期与实际、证据和缺口。状态使用“通过 / 失败 / 未执行 / 阻塞 / 不适用”，不适用说明理由；失败还应给出前置条件、复现步骤、影响与修复负责人。历史结果只证明历史版本，其他角色提供的观察要注明来源。敏感日志与大产物留在受控存储，公开文档只留脱敏索引。

界面变化按受影响流程补验真实宿主，包括主题、窄屏、长文本、键盘操作和异常状态。QA 交付同一版本的证据与缺口后，由设计和产品分别验收实际成品；测试通过不替代这两项结论或发布授权。

## 验收矩阵

### VSIX 1.0.1

下表连接业务预期与已有测试入口，表示覆盖设计，**不表示本轮执行结果**。自动化使用真实 Git、临时文件系统及模拟编辑器 API；评论面板测试执行 UI 脚本，不运行真实编辑器窗口。模拟面板的 `focus()` 不执行真实聚焦，CSS 的窄屏与高对比度规则也不能证明实际展示；键盘、辅助技术和选区草稿关闭重开后的完整恢复均需补验，具体边界见[界面设计](../设计/README.md)。

| 验收范围 | 应保持的结果 | 自动化入口 | 真实宿主补验 |
| --- | --- | --- | --- |
| 基点与创建 CR | 分支取共同祖先，提交取自身；默认值不改变已有 CR；任意有效 SHA 可选，取消不创建记录 | [baselines](../../test/baselines.test.cjs)、[commit-picker](../../test/commit-picker.test.cjs)、[editor](../../test/editor.test.cjs) | 安装重载后检查审阅设置、新建入口、SHA 输入和适用的 Git 菜单 |
| 内容与已审状态 | 比较已保存的工作区，stage / commit 不重置相同内容；改动后需复审，未保存不能标已审 | [review](../../test/review.test.cjs)、[editable](../../test/editable.test.cjs) | 在真实 Diff 编辑、保存、勾选并打开上次审阅后的变化 |
| 分支、CR 与陈旧页面 | 各轮进度与评论隔离；切分支或 CR 后旧页面不能写入另一轮 | [reviews](../../test/reviews.test.cjs)、[editor-context](../../test/editor-context.test.cjs) | 固定旧 Diff 标签，切换 CR 和分支后核对评论归属与提示 |
| 评论与定位 | 文件、目录、选区语义独立；重复片段或内容改变不猜测行号；评论删除可撤销 | [comments](../../test/comments.test.cjs)、[directories](../../test/directories.test.cjs)、[panel](../../test/panel.test.cjs) | 新增、编辑、删除、恢复及跳转；保存失败后草稿仍在 |
| 树与待处理概览 | 目录聚合进度与评论，常规刷新保留展开状态；概览可处理单条意见 | [tree](../../test/tree.test.cjs)、[panel](../../test/panel.test.cjs) | 深层目录、长文本、窗口缩窄、键盘操作和目标主题下检查可读性 |
| Agent 文件交接 | 指定 CR 路径稳定，清单可取回全文；回执匹配当前版本才待复核，不自动解决 | [reviews](../../test/reviews.test.cjs)、[comments](../../test/comments.test.cjs)、[pending-size](../../test/pending-size.test.cjs)、[editable](../../test/editable.test.cjs) | 复制交接说明，在可访问项目的 Agent 中处理，刷新并人工复核回复 |
| 恢复与永久删除 | 重启接续；归档可恢复；永久删除限定目标 CR，失败可重试，陈旧写入不能复活 | [review](../../test/review.test.cjs)、[reviews](../../test/reviews.test.cjs)、[purge](../../test/purge.test.cjs)、[pending-size](../../test/pending-size.test.cjs) | 重载后核对记录；在合成数据上归档、恢复和永久删除 |
| 文件与存储边界 | 只读 Git；链接不越界；损坏、冲突、限额和并发失败显式报错；忽略规则不破坏原文 | [review](../../test/review.test.cjs)、[comments](../../test/comments.test.cjs)、[ignore](../../test/ignore.test.cjs)、[purge](../../test/purge.test.cjs) | 按改动复验实际宿主的文件系统与权限错误；Remote SSH 单独验证 |

## 更新与交接

行为、接口、存储格式或支持环境变化时，QA 更新受影响场景并验证实际候选版本。缺陷修复只复测其影响范围与必要回归；源码未变的纯文档整理不重复已有全量测试。

[验证记录](验证记录.md)保留目前仍有用的发布证据和未关闭缺口。新结论写明替代的版本与范围，不用新日期刷新旧通过；受影响证据失效时立即改为待验证。临时脚本与本地产物若不随 checkout 提供，必须明示，并给出复现方法或文件哈希。

交接给项目负责人时，提供已测版本、环境、方法、结果、缺陷及可复查证据；未完成项附影响、下一责任和解锁步骤。涉及界面与流程的候选版本还需交设计、产品分别验收，任何单项通过都不等于发布许可。
