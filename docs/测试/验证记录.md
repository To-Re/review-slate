1. 调用 `reviewslate_probe_open`，预期 revision 0，且尚无 `state.json`。
2. 调用 `reviewslate_probe_save`，参数为 `{"expectedRevision":0,"reviewed":true,"comment":"QA synthetic comment"}`；预期 revision 1，返回状态与磁盘 JSON 一致。
3. 再以 expectedRevision 0 保存不同内容；预期 `isError: true`、磁盘字节保持步骤 2 的值、`write.lock` 释放。
4. 关闭 stdin 并等待子进程正常退出，在相同临时目录启动新进程，调用 `reviewslate_probe_read`；预期完全恢复步骤 2 的状态。
5. 仅把该临时目录的状态文件改为无效 JSON，再调用 read；预期 `isError: true`、损坏字节原样保留，没有被重建为空状态。退出进程并删除临时目录。

这些步骤本轮均通过。写入中断、磁盘满、权限拒绝、符号链接、同时写入和真实宿主撤销权限未在此探针执行；不得借现有 VSIX 测试为探针补记通过。
