## 当前 800 文件三轮性能

基线与当前候选各三轮独立合成仓库，800 个已跟踪文件全部修改，每侧约 2 KiB、每目录 40 个文件。首次选择时无现成 CR，对象缓存为空；随后为热路径。选择器直接接受基点，计到树模型生成，不含人工选择或 GUI 绘制。

下表单位为毫秒，表示中位数（最小—最大）。Diff 主指标为命令调用到 `vscode.diff` 请求；操作计数收集到队列全部空闲，可能包含请求之后的后台工作。刷新中点击开始前全仓扫描已经进入，扫描数只计其后新进入的扫描。

| 路径 | 基线 ms | 当前候选 ms | Git 子进程 | 新进入的全仓扫描 |
| --- | --- | --- | --- | --- |
| 选择基点 → 首次树模型 | 55663（53598–56257） | 1210（1155–1278） | 1620 → 24 | 2 → 2 |
| 空闲点击 → Diff 请求 | 546（545–717） | 192（184–225） | 7 → 6 | 1 → 0 |
| 切换文件 → Diff 请求 | 564（552–704） | 185（184–194） | 7 → 6 | 1 → 0 |
| 刷新中点击 → Diff 请求 | 1073（1009–1557） | 211（200–227） | 12 → 17 | 1 → 1 |
| 热刷新完成 | 583（528–648） | 359（343–375） | 7 → 7 | 1 → 1 |
| 单文件标已审 | 1264（1100–4214） | 851（709–968） | 14 → 14 | 2 → 2 |
| 40 文件目录标已审 | 2110（1938–2703） | 1648（1640–1702） | 14 → 14 | 2 → 2 |
| 8 次保存事件后空闲 | 5071（4731–5506） | 405（391–406） | 56 → 7 | 8 → 1 |

首次树的 `cat-file` 子进程从 1,600 次降至 4 次。空闲点击不再新增全仓扫描。刷新中点击仍会触发后台完整重扫，以免较早的扫描覆盖定向读取发布的新内容；因此此场景总 Git 次数为 17，高于基线 12，但点击先返回。当前 Diff 请求中位为 211 毫秒，队列最终空闲为 731（667–772） 毫秒；两个结束点不能混称“打开 Diff 耗时”。

模拟 `vscode.diff` 立即返回，不含原生 Diff 计算、语法高亮和绘制。预设事件测试不等于完整宿主事件覆盖，性能改善也不能抵消评论归属错误。

## 行为覆盖与真实事件根因

QA 对最后的小范围事件修复执行了必要增量，没有重跑全量套件：

```sh
node --test --test-name-pattern='真实预览替换|原生 Diff|标签先于编辑器|标签切到外部|编辑器归属' test/vsix-performance.test.cjs test/editor-context.test.cjs
```

新回归覆盖真实预览替换的空标签：打开 A→B→A 时，中间渲染不回退到旧对象；之后真正手动切换到非空标签仍使旧打开失效。其余四组核对标签与编辑器通知分开发生、完整 Diff 使用最新已读内容、增量 Diff 保持只读快照、外部 Diff 清理以及跨 CR / 共享 URI 归属。内容变化、未保存、目录成员、容量与持久化等现有规则由本轮完整 130 项测试覆盖；每项是否真实 GUI 仍单独判断。

现场缺陷的前置条件是原生 Diff 复用预览标签。修复前顺序切换 0000→0001→0000 时，树和 Diff 已更新，评论仍停在上一文件，额外截图确认不是瞬态。主负责人在受控合成项目的临时 trace 构建中取得真实事件，QA 回读 `artifacts/vsix-host-check/diagnostics/reproduced-trace.ndjson`（SHA-256 `14acf1d8c81ed948e7a209deddcce28c83122ca4fc0563c997dbf1ea1a32af4a`），确认 Diff 分派中活动标签短暂变空、活动编辑器仍为旧文件，导航版本增加后目标回退。31 次面板渲染、投递、Webview 接收和应用的 ID 序列一致，支持本次错误来自扩展状态回写。

当前修复在 Diff 分派中遇到空标签时不增加导航版本、不借旧编辑器重设目标，仍允许实际非空标签切换使旧请求失效。模拟新增用例由客户端报告修前失败；QA 独立确认当前版本通过。根因 trace 与下文修复后的真实宿主复验分别记录。
