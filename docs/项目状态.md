## 仍影响下一步的缺口

真实 Codex 的工具已能发现并调用本地探针，但面板显示、点击保存和重启恢复尚无完整实机证据。客户端研发负责确认这组能力；QA 区分工具调用、模拟/独立宿主和真实宿主的结果。未取得证据前不能宣布 Codex 审阅插件可用。

探针采用本机开发配置，只保存合成标记和评论，不能直接作为公开安装包。客户端研发应确定可移植打包、运行时和宿主回收方式；客户端研发负责仓库与存储适配。当前没有 HTTP 服务或跨应用同步需求。

## 已确认的范围决定

- 产品名只用 **ReviewSlate**；不增加中文别名。
- Codex 的目标是类似编辑器扩展的人工 Git 审阅体验；文件列表、Skill 或自动审查文字不能代替它。
- 每个应用独立保存进度；首版不做数据互通、同步或迁移。
- 保持轻量，插件不引入额外登录、HTTP 监听或常驻后台服务；宿主管理的 stdio 子进程是当前核查方向。宿主自身的登录与权限要求仍适用。
- 同一分支与固定基点重新打开已有未归档 CR，保留进度。
- 文档按角色分目录，由领域负责人维护；新文档核查后删除旧文档，不保留兼容副本或归档目录。
