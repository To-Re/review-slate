## 已确认的范围决定

- 产品名只用 **ReviewSlate**，不增加中文别名。
- Codex 提供类似编辑器扩展的人工 Git 审阅体验；文件列表、Skill 或自动审查文字不能代替工作区。
- 每个应用独立保存进度，不做跨应用数据互通、同步或迁移。
- 不引入额外登录、HTTP 监听或常驻后台服务；使用宿主管理的 stdio 子进程，安装包捆绑运行时。
- 仓库选择以系统文件夹选择窗口和最近项目为主入口；手动输入路径作为备用。取消或选错目录不切换当前项目、不丢草稿和进度。
- 支持中文、英文及跟随宿主；手动偏好本地保存，切换不丢草稿和进度。
- 同一分支与固定基点接续已有未归档 CR，保留进度。
- 一个客户端研发方向覆盖本地逻辑与界面；共用规则与各宿主适配分离，修改共用部分验证旧 VSIX。
- 每个角色一个文档目录，领域负责人直接维护现行正文；旧文档被替代后清理，不保留历史副本。
