## 固定范围

- `main` 只维护 VS Code 系 VSIX；Trae / Trae CN 继续作为兼容目标。
- Codex 开发留在 [beta](https://github.com/To-Re/review-slate/tree/beta)，不将整个分支合并到 `main`。通用优化须独立评估并验证。
- 不改变扩展 ID、命令、已有审阅数据格式或存储位置，不用清空进度换取性能。
- 不能通过省略内容检查、使用过期 Diff 或弱化分支／CR 归属检查提速。
- 测试使用合成仓库；测量扩展逻辑与实际编辑器显示时分别标注证据边界。
- 文档按一个角色一个目录维护，直接替换旧稿并修复引用，不保留兼容页或归档副本。

用户的已有项目窗口重载到新版后，已确认 Diff 和评论恢复正常。此反馈不扩大合成仓库测量的性能或跨宿主覆盖范围。
