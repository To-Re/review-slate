## 持续维护边界

- `main` 只维护 VS Code 系 VSIX；Codex 的进行中工作保留在 [beta](https://github.com/To-Re/review-slate/tree/beta)，不整分支合并。
- 当前版本保留扩展 ID 和既有命令，新增筛选入口，不更改已有审阅数据格式或存储位置。
- 后续性能优化继续核对内容新鲜度和分支、CR 归属，不通过清空进度或省略校验提速。
- 有评论空态、定位代码按钮、未保存和读取失败的真实界面、完整关闭重开、其他主题及 VS Code / Trae / Remote SSH 的实机覆盖仍待补齐；现有定向结果不扩大为全部兼容性保证。
- 文档按一个角色一个目录维护，替换旧稿并修复引用，不保留过期副本。
