# 路线图

以下是未来方向，**不属于 1.0 已实现功能**，没有承诺发布时间。

## DeepSeek Harness 集成

- [ ] 明确 Harness 中的安装、任务入口与最小权限需求。
- [ ] 让 Agent 能接收指定 CR 的清单，核对仓库、分支和基点，并按现有回执约定返回处理结果。
- [ ] 设计用户确认、失败提示和中断恢复，避免自动处理其他 CR 或代替用户解决评论。

## Codex 插件集成

- [ ] 评估适用的 Codex 插件入口与分发方式。
- [ ] 提供接收审阅意见、定位上下文和写回回执的完整流程。
- [ ] 明确本地与远程工作区的可访问范围，并在真实宿主验证安装和交接。

## 集成约束

保持轻量，安装后即可使用，不增加常驻本地服务器、同步服务或额外部署步骤。优先复用明确的文件协议与宿主能力；如果未来需要网络、身份或额外权限，须在实现前明确设计与用户可见的数据流。

优先复用 ReviewSlate 已有数据与文件协议；宿主边界不适合共享或共享成本过高时，可采用独立存储。数据导入、迁移和冲突规则需另行设计。当前版本只提供本地文件交接和回执，不包含上述专用插件、自动 Agent 调用或跨宿主进度同步。
