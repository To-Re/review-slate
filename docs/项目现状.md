## 分支与版本

`main` 只维护 VS Code 系 VSIX，兼容目标包括 Trae / Trae CN。当前版本为 **1.0.2**，安装包与发布日期见 [1.0.2 Release](https://github.com/To-Re/review-slate/releases/tag/v1.0.2)。本版改进新建审阅后目录树展示、打开 Diff 的性能，修复连续切换时的评论目标同步，并按角色重写主分支文档。功能源码来自已通过 macOS / Ubuntu CI 的 `cb9f9a1`；正式发布准备只更新文档，运行代码和数据格式保持不变。

Codex 的开发源码与文档保留在 [beta 分支](https://github.com/To-Re/review-slate/tree/beta)。主分支不包含该客户端的入口、运行时或依赖，也不维护其在途任务。

## 实现与数据边界

扩展使用 TypeScript、VS Code 扩展 API 和 Node.js 内置模块。树与 Diff 使用原生控件，评论区使用受限本地 Webview。Git 调用只读，不 fetch、切分支、创建对象或修改索引；运行时无网络上传、遥测、模型调用或 HTTP 服务。

完整 Diff 的可编辑侧保存到真实工作区。评论初始化会按需补充根 `.gitignore` 的 `/.code-review/`。审阅资料为普通本地文件，可能包含代码、评论和绝对路径；完整备份需保留项目资料与宿主扩展存储两处。不同宿主不自动同步或迁移。字段与恢复边界见[数据协议](客户端/数据协议.md)，信任前提见[安全](安全/README.md)。

## 验证与限制

1.0.1 在 macOS / Trae CN 3.4.11（内核 1.107.1）实测了安装、重载、审阅设置、新建入口、SHA 输入与 Git 图形菜单显示。VS Code、Trae、Remote SSH 尚无该版本完整实机验收；兼容目标不能表述为已验证支持。

本轮性能前后对比、自动回归和人工验证分别记录在[测试记录](测试/验证记录.md)，代码与披露结论分别见[代码评审](代码评审/README.md)和[安全](安全/README.md)。合成仓库或模拟编辑器的耗时不代表实际宿主的完整屏幕呈现耗时。

1.0.2 使用有界并发与批量 Git 对象读取，打开单文件 Diff 不再先扫描全仓或等待后台刷新；异步结果发布时检查导航身份与视图版本。最终全套自动检查为 130 项：129 通过、1 项可选性能采样跳过、0 失败，VSIX 打包通过。800 个变更文件的合成仓库三轮中位数：首次树从 55,663 ms 降至 1,210 ms，空闲点击到 Diff 请求从 546 ms 降至 192 ms，刷新期间点击从 1,073 ms 降至 211 ms；测量不含原生编辑器渲染。

实际 Trae CN 检查发现并修复了原生预览切换时短暂空标签造成的评论目标回退，真实事件记录与修复前失败、修复后通过的回归用例互相印证。1.0.2 的同一运行代码已安装并在新的 Trae CN 宿主窗口通过定向复验：连续与快速切换文件时，树选择、Diff 和评论对象一致，复用预览标签；目录和待处理模式保持，已有 1/800 已审进度恢复。独立代码审核与 QA 的增量检查通过。完整任务验收与不同宿主的覆盖范围分别记录。

评论定位不做 AST 或自动改名跟踪。二进制、大文件、符号链接、Git 过滤器、子模块与未保存内容有明确限制；读取失败不得显示成功或记录已审。恢复审阅数据不等于已经验证全部标签、目录展开和光标位置都能恢复。
